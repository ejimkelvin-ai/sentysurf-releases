Help

Which download do I need?

The Download button picks the right one for you. If you're downloading for another PC: most PCs (Intel or AMD) need the standard version; ARM laptops (Snapdragon, many Copilot+ PCs) need the ARM version. To check, open Settings → System → About and look at System type. “ARM-based processor” means you need the ARM64 build.

Requirements

  • Windows 10 (version 1809 or newer) or Windows 11, 64-bit
  • An administrator account to install (every account on the PC is protected afterwards)
  • Not supported: Windows in S mode, 32-bit Windows

“Windows protected your PC”

SentySurf isn't code-signed yet, so Windows SmartScreen shows a blue warning for new downloads. Click More info → Run anyway. You can check your download is genuine with its fingerprint (below).

“Smart App Control blocked an app”

On PCs with Smart App Control turned on, Windows blocks apps that aren't code-signed and there's no way to allow a single app. SentySurf can't run on these PCs until it's signed. (Smart App Control can be turned off in Windows Security → App & browser control, but it can't always be turned back on, so think carefully.)

Nothing happens, or “This app can't run on your PC”

The PC may be in Windows S mode, which only allows Microsoft Store apps, or you may have downloaded the wrong build for its processor. See Which download do I need?

My antivirus quarantined it

Some antivirus products wrongly flag new, unsigned apps. Check the file's fingerprint (below), then restore it or add an exception.

Check your download

Every release includes SHA256SUMS.txt on the release page. In PowerShell, in the folder with the download:

Get-FileHash .\SentySurf-Setup-*.exe

The hash should match the line for that file.

Updates

SentySurf checks for a new release every 6 hours. With Install updates automatically on (the default), updates are verified against their published SHA-256 checksum and installed in the background while the window is closed. You can also install from Settings → Updates.

Installing on a Mac

  1. Download the disk image for your Mac: Apple silicon (M1 or newer) or Intel. Not sure? Apple menu > About This Mac shows the chip.
  2. Open it and drag SentySurf onto Applications. Always run it from Applications, not from the disk image.
  3. The first time you open it, macOS may say it can't verify the developer, because SentySurf isn't notarised by Apple yet. Open System Settings > Privacy & Security, scroll down and click Open Anyway. Only do this for a copy you downloaded from sentysurf.com and, ideally, checked.
  4. Turn on Live protection in the app. It starts by itself when you log in, and you can turn it off at any time.

Updates: SentySurf tells you when a new version is out, downloads the disk image and checks its checksum. Drag the new copy onto Applications and choose Replace.

Sending SentySurf to a SIEM

Open Settings > SIEM & log forwarding and turn on any destination, then click Send test event:

  • Windows Event Log: Application log, source SentySurf, event IDs 1000 (info), 2000 (low), 3000 (medium) and 4000 (high). Collect it with Windows Event Forwarding, Microsoft Sentinel's Azure Monitor Agent, the Splunk Universal Forwarder, Elastic Agent or Wazuh.
  • Syslog: RFC 5424 over UDP, TCP or TLS, with CEF (ArcSight, QRadar, Sentinel's CEF connector) or JSON as the message.
  • HTTPS collector: Splunk HTTP Event Collector (sourcetype sentysurf:json) or any JSON webhook. Addresses must use https.
  • JSON log file: one Elastic Common Schema event per line in SentySurf's data folder, for file-tailing agents.

SentySurf sends alerts and, after each scan, a summary plus every finding. Nothing is sent anywhere unless you turn a destination on.

Where did Password check and Allowlist go?

Since version 2.15, Password check is part of Safety check, alongside the link and file checks. The Allowlist lives in Settings under Manage allowlist.

A game or app can't save files after turning on ransomware protection

Controlled Folder Access blocks apps it doesn't know from writing to your protected folders. Open Live protection → Ransomware protection, find the app under Recently blocked and click Allow, or use Allow an app…. Only allow apps you trust.

The Network page shows a device I don't recognise

Phones and laptops often use a private (rotating) address, so the same phone can appear as a new device after an update. Check your phones, TVs, consoles and smart-home gadgets first. If it still doesn't match anything, change your Wi-Fi password and review the router's connected-device list. Use Mark as known and Rename to label devices you trust.

Adding a family PC

  1. On your PC: SentySurf → Family → Create family. You get a family code.
  2. On their PC: install SentySurf from this website.
  3. On their PC: SentySurf → Family → Join a family, type the code, click Join family.

Their PC appears on your Family page within a few minutes. Send the code by text or phone, not in the same email as the download link. Click Refresh on the Family page to ask every PC to check in now.

Work or school computers

Your IT department's rules may block installing apps. Ask them first.
